# Tascat 要件定義

## 1. 目的

Tascat は、個人が頭の中の「やること」を整理し、タスク完了後に猫へごはんを与える短い休息を挟むことで、次の生活行動へ気持ちを切り替えやすくするローカルファーストの ToDo Web アプリケーションである。

提供価値は次の一方向の小さなループに限定する。

1. タスクを登録・確認する
2. 必要ならサブタスクを順に完了する
3. 親タスクを完了し、ごはんを 1 食獲得する
4. 好きな時に猫へごはんを与える
5. 短い Eat アニメーションの後、Stand Idle に戻る

競争、育成、継続率を煽る仕組みは目的に含めない。

## 2. 対象ユーザーと利用前提

- 対象は個人利用者 1 人
- アカウント、ログイン、同期なしで直ちに使える
- 主利用環境は 1280×720 以上、表示倍率 100% の PC
- 最新安定版の Chrome、Edge、Firefox、Safari を対象とする
- 小画面や拡大表示では縦スクロールを許容し、横スクロールを防ぐ

## 3. 機能要件

### 3.1 ナビゲーション

基本画面はホーム、カレンダー、ポモドーロ、設定の 4 画面のみとする。PC では左固定サイドバーを使い、現在地を文字、形、色で明示する。小画面では同じ 4 項目をコンパクトなナビゲーションとして表示する。

### 3.2 タスク

- ホームには期限に関係なく未完了タスクをすべて表示する
- 並び順は「登録順」と「優先度が高い順」の 2 種類
- 検索とフィルターは設けない
- 追加と編集は同一のモーダルを再利用する
- タスク名は必須。メモ、期限、時刻、繰り返し、優先度、カテゴリ、サブタスクは任意
- 期限ショートカットは今日、明日、日付
- 今日、明日、日付を指定しなければ期限なし
- 時刻は期限がある場合のみ設定可能
- 優先度は高、中、低。未指定も許容する
- カテゴリは仕事、プライベート、その他の固定 3 種。未指定も許容する
- 未完了、完了済みのどちらも確認後に削除可能
- 完了済みはホーム下部の折りたたみ領域へ移動し、初期状態は閉じる
- 完了解除で未完了へ戻せる
- 未完了と完了済みはそれぞれ 1 ページ 2 件でページネーションする。拡大した文字と操作領域を優先する

入力上限は、読みやすさと localStorage の予測可能性のため次の通りとする。

- タスク名: 1〜120 文字
- メモ: 0〜2,000 文字
- サブタスク名: 1〜120 文字
- サブタスク数: 任意（UI 上で逐次追加・削除可能）

### 3.3 サブタスク

- サブタスクが持つ情報は ID、タイトル、完了状態のみ
- 未完了サブタスクが 1 件でもあれば親タスクを完了できない
- 完了を試みた場合は、そのタスク内の説明と live region で「すべてのサブタスクを完了してください」と伝える
- サブタスク完了ではごはんを付与しない

### 3.4 繰り返し

- なし、毎日、毎週、毎月の 4 種類
- 繰り返しには基準日が必要なため、期限なしの状態で繰り返しを選ぶと期限を今日に設定する
- 完了した発生分は完了済みに残し、次回分を未完了で 1 件だけ生成する
- 毎日は翌日、毎週は 7 日後、毎月は翌月
- 毎月は作成時の基準日を保持し、存在しない日はその月の末日に丸める。例: 1 月 31 日 → 2 月末日 → 3 月 31 日
- 完了解除で生成済みの次回分を削除しない
- 再完了でも同じ次回分を生成しない

### 3.5 報酬と猫

- 親タスクを初めて完了した時だけ、ごはんを 1 食付与する
- `rewardClaimed` は完了解除、再完了、タスク削除でも戻さない
- ごはんの所持上限は設けない
- ごはんが 1 食以上あり、猫が食事中でない時だけ「ごはんをあげる」を実行できる
- 実行時に 1 食を同期的に減らして Eat を 1 回再生し、終了後 Stand Idle のループへ戻る
- 連打、重複イベント、再描画でもごはんを負数にしない
- ごはん 0 または食事中の無効状態は、文言と `disabled` 属性でも示す
- 猫は提供された 1 匹だけを使用し、Animation 7 Stand Idle と Animation 8 Eat 以外を使わない
- Cat Animation List.png はフレーム確認専用であり、画面や配布物には組み込まない
- 音声、効果音、BGM、鳴き声は一切使わない

### 3.6 カレンダー

- 月表示で前月・次月へ移動できる
- 日付セルに当日の未完了・完了件数と状態を、文字・記号を含めて表示する
- 日付選択で当日の未完了・完了タスクを一覧表示する
- 選択日の「タスク追加」で、同日を期限の初期値にした共通タスクモーダルを開く

### 3.7 ポモドーロ

- 集中 25 分、休憩 5 分で固定
- 開始、一時停止、再開、リセットを提供する
- 終了予定時刻を基準に残り時間を計算し、バックグラウンドや再読み込みによるずれを抑える
- 集中終了後は休憩モード、休憩終了後は集中モードへ切り替えるが、自動開始しない
- 画面内の明確な文言で終了を知らせる。通知と音は使わない
- 履歴、統計、タスク連携、ごはん付与は行わない

### 3.8 設定

- データ: 確認後に全ユーザーデータを削除する
- アプリ情報: Tascat とバージョンを表示する
- 削除対象はタスク、サブタスク、完了・報酬状態、ごはん、タイマー状態、画面上の利用設定を含む

### 3.9 永続化

- データは現在のブラウザ・端末の localStorage にだけ保存する
- 外部送信、アカウント、クラウド同期、読み込み、書き出し、バックアップは行わない
- 保存データには schema version を持たせる
- JSON 解析または構造検証に失敗した場合は技術的な例外を表示せず、初期状態で安全に起動して説明を表示する

## 4. 非機能要件

### 4.1 アクセシビリティ

WCAG 2.2 Level AA を目標とし、次を必須とする。

- セマンティック HTML、明示ラベル、適切なボタンとリンク
- キーボードのみで主要操作が完結
- 2px 以上の高コントラストな `:focus-visible`
- 色だけに依存しない優先度、完了、無効、現在地の表示
- ネイティブ dialog を基礎にしたフォーカス拘束、Escape 閉じ、呼び出し元へのフォーカス復帰
- エラーを入力項目と関連付け、live region でも通知
- `prefers-reduced-motion` では猫の常時ループを静止し、食事は短い状態表示で意味を保つ
- 200% 拡大や狭い表示で情報・操作を失わず、横スクロールを発生させない

### 4.2 レイアウトと性能

- 1280×720、100% ではページ全体の縦・横スクロールを発生させない
- 件数増加はページネーションで処理し、文字や行高を極端に縮めない
- 小画面と拡大時は縦スクロールを許容する
- 初回ロード後の機能は外部通信に依存しない
- スプライトは整数倍率と `image-rendering: pixelated` で表示する

### 4.3 品質

- TypeScript、lint、build、Unit、Integration、主要 E2E をすべて成功させる
- 自動アクセシビリティ検査を E2E に含める
- 主要ロジックは UI から分離した純粋関数または reducer としてテストする
- localStorage 書き込み失敗時も現在の操作をクラッシュさせず、保存できない旨を平易に伝える

## 5. 禁止事項

次を実装しない。

- 課金、広告、認証、AI、SNS、チャット、ランキング、通知、外部サービス連携
- サーバー、外部 API、クラウド同期、解析、監視、SEO、PWA
- レベル、経験値、通貨、空腹度、ペナルティ、好感度、成長、着せ替え、猫選択、名前変更
- 実績、バッジ、連続達成、スコア、派手な報酬演出、パーティクル
- アップロード、インポート、エクスポート、バックアップ
- 高度な繰り返し、期日順ソート、検索、フィルター、履歴、統計
- 白基調 SaaS、既製 UI の無加工利用、巨大な角丸、ガラス、過剰なグラデーション、ネオン、3D

## 6. 仕様整合性の確認結果

- 「PC でページ全体をスクロールしない」と「拡大時の Reflow」は、PC 通常時だけ viewport 固定＋ページネーション、小画面・拡大時は文書縦スクロールへ切り替えることで両立する。
- 「永続化」と「外部同期なし」は、単一スナップショットを localStorage へ保存することで両立する。
- 「完了解除」と「1 タスク 1 食」は、完了状態と報酬取得状態を独立させることで両立する。
- 「繰り返しの完了解除」と「重複禁止」は、生成元タスクに次回生成済み ID を記録し、完了解除で消さないことで両立する。
- 明示仕様に重大な矛盾はない。期限なしで繰り返しを選んだ場合と月末処理だけを、上記の予測可能な規則として確定した。
